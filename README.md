# 🍅 ポモドーロタイマー

シンプルなコマンドラインのポモドーロタイマーです。集中と休憩を繰り返して生産性を高めましょう。

## 機能

- ⏱ 25分の作業セッション
- ☕ 5分の短い休憩
- 🌟 4セッションごとに15分の長い休憩
- 📊 セッション履歴の自動保存
- 🎨 カラー表示 & プログレスバー

## 使い方

```bash
python pomodoro.py
```

Python 3.6以上が必要です。

## カスタマイズ

`pomodoro.py` の先頭にある定数を変更することで、タイマーの時間を調整できます。

```python
WORK_MINUTES  = 25   # 作業時間（分）
SHORT_BREAK   = 5    # 短い休憩（分）
LONG_BREAK    = 15   # 長い休憩（分）
SESSIONS_UNTIL_LONG = 4  # 長い休憩までのセッション数
```
